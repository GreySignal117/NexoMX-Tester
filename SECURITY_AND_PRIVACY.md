# Seguridad y privacidad

- Este build funciona sólo en `127.0.0.1`; no está disponible para otros equipos de la red.
- No requiere cambiar Firewall, abrir puertos ni instalar extensiones.
- Tu cuenta y contraseña son locales. No existe una contraseña compartida de prueba.
- El setup genera una clave de sesión distinta para tu usuario de Windows y nunca la muestra.
- Usa solamente datos sintéticos. No cargues datos reales, personales, empresariales, credenciales ni documentos de terceros.
- No envíes passwords, secret keys o información privada en bugs, feedback o screenshots.
- Al resetear se elimina el espacio de datos sintéticos de esta prueba.

Este build no recopila analítica remota ni telemetría.
