# Instalación en Windows

1. Extrae el ZIP.
2. Abre la carpeta extraída.
3. Haz doble clic en `SETUP_NEXOMX_TEST.cmd`.
4. Si Windows pregunta si deseas ejecutar el archivo, confirma sólo si descargaste el ZIP desde la versión `SUA1-T01` de este repositorio oficial de GitHub y verificaste su SHA-256.
5. Espera a que termine la preparación. No necesitas instalar Python ni descargar componentes adicionales.
6. Cuando se solicite, crea un usuario local y una contraseña de al menos 12 caracteres.

La configuración crea una clave de sesión única para tu cuenta de Windows. No se muestra ni se guarda dentro de este ZIP.

Esta distribución incluye sus componentes de ejecución. No descargues ni sustituyas archivos ejecutables de sitios desconocidos.
