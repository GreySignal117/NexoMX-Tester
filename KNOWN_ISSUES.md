# Problemas conocidos

Estos puntos están registrados para mejora. No necesitas resolverlos para continuar la prueba.

1. El selector de tipo de relación puede usar apariencia nativa y mostrar valores internos en inglés aunque hayas elegido español.
2. Algunas etiquetas, título o navegación de Traceability pueden permanecer parcialmente en inglés al usar español.
3. Windows puede presentar problemas de longitud de ruta si extraes o trabajas desde una ubicación con muchas carpetas anidadas. Extrae el ZIP en una ruta corta, como Descargas, y deja que el setup use `C:\NexoMX-SUA1`.
