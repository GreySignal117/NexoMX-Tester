# Resetear o eliminar la prueba

## Resetear los datos sintéticos

1. Haz doble clic en `RESET_NEXOMX_TEST.cmd`.
2. Lee el aviso.
3. Escribe `RESET` sólo si aceptas eliminar tus Cases sintéticos, archivos cargados y tu cuenta local de esta prueba.
4. Ejecuta `SETUP_NEXOMX_TEST.cmd` otra vez para crear una instalación limpia.

## Eliminar por completo

1. Haz doble clic en `STOP_NEXOMX_TEST.cmd`.
2. Elimina la carpeta extraída del ZIP.
3. Elimina `C:\NexoMX-SUA1`.

Esto elimina únicamente datos de esta prueba sintética. No elimina otros programas ni cambia configuraciones de red o Firewall. La clave de sesión de Windows creada para NexoMX puede permanecer como un valor local no útil; si deseas retirarla, avisa a Product para recibir instrucciones verificadas.
